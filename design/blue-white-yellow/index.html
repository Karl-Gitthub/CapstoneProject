01 · Login

Redesign concept · Editable SVG · Full-size PNG
  • Replace the oversized borderless login with a compact, resizable native window.
  • Remove department selection: derive role and program from the verified account.
  • Keep sign-in primary; separate password recovery and access requests.

02 · Request staff access

Proposed feature · Editable SVG · Full-size PNG
  • Replace the hardcoded ADMIN gate with an approval or invitation workflow.
  • Do not allow users to choose privileged roles during registration.
  • Confirm receipt with the same response regardless of account existence.

03 · Password recovery

Proposed feature · Editable SVG · Full-size PNG
  • Add a real recovery provider before enabling this link.
  • Use neutral responses that do not expose registered accounts.
  • Preserve the same field and button positions as login.

04 · Registrar workspace

Proposed workspace · Editable SVG · Full-size PNG
  • Use a work queue rather than oversized vanity metrics or decorative charts.
  • Keep student search and common tasks within one click.
  • Show only counts that correspond to a real filtered list.

05 · Student directory

Redesign concept · Editable SVG · Full-size PNG
  • Replace dense vertical cell borders with readable horizontal row separators.
  • Keep program filtering next to search; put term selection in enrollment and grade contexts.
  • Make the selected record and its next action explicit.

06 · Student profile

Redesign concept · Editable SVG · Full-size PNG
  • Use one student record with tabs instead of unrelated windows for each document.
  • Keep the student identity visible while changing tabs.
  • Separate record completeness from enrollment or academic standing.

07 · Student identity

Redesign concept · Editable SVG · Full-size PNG
  • Group fields into four stable sections instead of a long paper-like canvas.
  • Use calendar controls and derive age from birth date.
  • Validate inline and retain every entered field after failure.

08 · Student contact and address

Redesign concept · Editable SVG · Full-size PNG
  • Use complete address labels instead of unexplained abbreviations.
  • Preserve phone numbers and postal codes as text, including leading zeros.
  • Keep personal contact data off list screens and dashboard summaries.

09 · Student prior education

Redesign concept · Editable SVG · Full-size PNG
  • Give primary and secondary education their own clearly separated groups.
  • Use a year field rather than a full date picker for year completed.
  • Avoid duplicate labels with unclear school-year meaning.

10 · Student credentials

Redesign concept · Editable SVG · Full-size PNG
  • Replace a wall of unrelated dropdowns with a document checklist.
  • Distinguish Missing, Received and Not applicable using words and color.
  • Show review notes only when there is an action to take.

11 · Enrollment workspace

Redesign concept · Editable SVG · Full-size PNG
  • Use an editable subject grid instead of eight repeated subject-code fields.
  • Keep the term and student identity visible throughout enrollment.
  • Show totals and conflicts next to the confirmation action.

12 · Coordinator workspace

Redesign concept · Editable SVG · Full-size PNG
  • Scope the whole workspace to the coordinator’s program rather than showing disabled other-program buttons.
  • Keep pending registrations and unassigned teaching loads as the main work lists.
  • Avoid unrelated registrar actions in coordinator navigation.

13 · Pending registration review

Redesign concept · Editable SVG · Full-size PNG
  • Use a split review layout so the queue stays visible.
  • Replace vague Submit and Update buttons with actions that name the outcome.
  • Require a clear correction reason; avoid silently rejecting a record.

14 · Faculty details and loading

Redesign concept · Editable SVG · Full-size PNG
  • Separate faculty profile editing from teaching-load assignment.
  • Replace repeated code fields with an assignment table.
  • Show course, section, term and instructor together to prevent ambiguous assignments.

15 · Faculty workspace

Redesign concept · Editable SVG · Full-size PNG
  • Show only assigned classes. Remove the need to retype a faculty username.
  • Make grade completion visible at the class level.
  • Use class-specific actions instead of a generic dashboard full of metrics.

16 · Grade entry

Redesign concept · Editable SVG · Full-size PNG
  • Use in-grid editing with one save action, rather than repeated Add, Calculate and Confirm controls.
  • Keep calculated average/equivalent fields read-only.
  • Display unsaved changes and stale-record conflicts explicitly.

17 · Curriculum evaluation

Redesign concept · Editable SVG · Full-size PNG
  • Use a year/semester outline instead of one very long fixed-position form.
  • Preserve course order and show passed, incomplete and not enrolled as distinct states.
  • Keep evaluation and official transcript output separate.

18 · Reports workspace

Redesign concept · Editable SVG · Full-size PNG
  • Consolidate four Generate buttons into one report workspace.
  • Make student, class and term requirements explicit for each document.
  • Separate filter controls from the document page; preview the exact print layout.

19 · Copy of grades

Redesign concept · Editable SVG · Full-size PNG
  • Use an actual print preview with consistent A4 margins and restrained institutional branding.
  • Keep toolbars off the printed page.
  • Require verified grades before producing an official document.

20 · Computed class grades

Redesign concept · Editable SVG · Full-size PNG
  • Keep this screen read-only and visually distinct from grade editing.
  • Align numeric columns and use a consistent number of decimal places.
  • Use one class/term context rather than repeating faculty identity fields.

21 · Alphalist preview

Redesign concept · Editable SVG · Full-size PNG
  • Sort names alphabetically and make program, year, section and term visible.
  • Remove Clear and generic Go back actions from the print canvas.
  • Use repeatable table headers and page numbering for longer rosters.

22 · Transcript preview

Redesign concept · Editable SVG · Full-size PNG
  • Use the school’s approved transcript template and official signatory rules.
  • Separate document generation permissions from ordinary record access.
  • Do not invent seals, signatures, certification language or official claims.

23 · Staff access administration

Proposed feature · Editable SVG · Full-size PNG
  • Replace the desktop admin password panel with a real authorized administration area.
  • Separate role from program scope and class assignment.
  • Require explicit review and an audit record for access changes.

24 · Navigation and interaction states

Design foundation · Editable SVG · Full-size PNG
  • Reuse a single shared navigation component per role.
  • Keep yellow out of body text and large background areas.
  • Maintain keyboard focus, adequate contrast and stable control spacing.

25 · Empty error and save states

Design foundation · Editable SVG · Full-size PNG
  • Replace vague errors and console-only failures with useful in-context messages.
  • Never show success before persistence completes.
  • Preserve unsaved input and give a clear recovery action.
